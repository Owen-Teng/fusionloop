**原始论文**是作者研究内容的依据；**网页导读**为阅读便利重组原稿；**空白工具和提示词**是基于论文的编辑性操作化。导读、翻译与工具使用 AI 辅助整理，不构成新的实证结果，也不代表外部研究机构为本假设背书。
