## 怎样使用这些资料

外部材料分别包含实验研究、综述、调查、情景判断和企业自述。它们帮助理解问题与设计验证，不能被合并包装成 FusionLoop 已获得验证。目录是精选配套材料，不等于论文提到的完整底层资料库。原始研究的证据截止日期仍为 **2026-08-21**；本阅读包整理于 **2026-10-23**。
