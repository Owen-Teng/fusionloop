正式岗位继续承载劳动关系、职责权限、专业资格、职级薪酬、职业归属和法律风险责任。工作变化可以引发岗位重组、合并、新设或退出，但依据应当来自多周期真实工作。

![论文原图：组织孪生图](../assets/paper/twin-maps.jpeg)

## 两张图相互校验

| 岗位图 | 工作运行图 |
| --- | --- |
| 这个人承担什么正式职责与权限？ | 真实结果怎样完成？ |
| 资格、职级、薪酬、专业归属与职业路径 | 人在哪里判断、Agent 执行什么、能力怎样流动 |
| 为真实工作提供正式授权 | 用运行证据反向检验岗位与制度安排 |

这两张图共同构成**组织孪生图**。变化的顺序是：先看工作是否持续改变，再讨论岗位职责、能力标准、职级、编制和绩效规则如何调整。单张岗位图、单次成功或平均 AI 提效数字都不足以作出人员结论。

## 岗位说明需要增加什么

- 对什么完整业务结果负责，以及与上下游的边界。
- 哪些判断、承诺、签署和例外不可让渡。
- 可以在什么权限与容量下调用哪些能力。
- 需要维护、更新和传承哪些知识、Skill、Agent 与方法。

不是所有工作都必须画成 Loop。具备重复触发、可验收结果和反馈学习条件的工作，才适合升级为 FusionLoop 图。高信任关系、复杂谈判、危机处置和高风险人事决定仍需保留人的前台责任。
