## 结果边界

从经业务和编制规则批准的人才需求开始，到**合适外部人才接受条件、按承诺到岗，完成向用人团队的正式交接，进入可开始贡献的状态**。筛选、面试、发出 Offer 都不是单独的终点。

![原图 8：人才供给](../assets/paper/talent-supply.jpeg)

| 设计要素 | 原稿安排 |
| --- | --- |
| Loop Owner | 人才供给结果负责人 |
| 协同专业 | 招聘、用人负责人、薪酬、文化、员工体验、法务与 IT |
| Agent 任务 | 市场扫描、候选人搜索与匹配、沟通排程、材料检查、风险提示、进度跟踪 |
| 人的判断 | 需求合理性、最终选择、薪酬例外、隐私、公平、劳动承诺与正式交接 |
| 验收 | 按约到岗、用人团队正式接收、具备开始贡献条件 |
| 回写 | 渠道质量、画像偏差、面试效度、Offer 接受／拒绝原因、到岗与早期表现 |

Agent 不得独立作出最终录用、薪酬例外、劳动文件签署或敏感人事决定。用人负责人保留需求责任、最终选择权和接收责任。

## 下游培养单独承接

融入、培养和岗位上手，由用人负责人主责的后续 Loop 承接。早期表现可以反馈招聘有效性，不能把后续表现全部因果归给招聘。

## 专业协作与跨 Loop 复用要分开

一个人才供给 Loop 内多专业协作，不自动成为跨团队复用。若同一套文化沟通方法既用于人才供给，也由另一项融入工作独立采用并产生结果，才可能形成跨工作复用证据。
